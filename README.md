# plainrecords-fsis

A daily copy of the USDA FSIS recall list (meat, poultry and egg products), fetched from FSIS's public recall API by a GitHub Actions
runner in the United States, for plainrecords.com. FSIS answers requests from outside the U.S. with "Access Denied".

The data is a U.S. government work (public domain). Source: https://www.fsis.usda.gov/recalls. Only the API's own fields are kept.
